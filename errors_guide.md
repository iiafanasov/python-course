# Что делать, если программа выдала ошибку

## Алгоритм

1. Прочитай **последнюю строку** сообщения: там тип ошибки и подсказка.
2. Найди **номер строки** (`line 7`) и посмотри на неё и на строку выше.
3. Сравни с таблицей ниже.
4. Выведи значения переменных через `print(...)` перед строкой с ошибкой.
5. Только после этого зови учителя.

## Частые ошибки

| Ошибка | Что значит | Где искать |
| --- | --- | --- |
| `SyntaxError` | Python не понял запись | Двоеточие после `if`/`for`/`while`, закрытые кавычки и скобки |
| `IndentationError` | Неправильный отступ | Тело `if`/`for`/`while` сдвинуто на 4 пробела |
| `NameError` | Такого имени нет | Опечатка в имени переменной, переменная ещё не создана |
| `TypeError` | Действие не подходит для такого типа | Строка + число: `"Очки: " + 5` → используй f-строку |
| `ValueError` | Неверное значение | `int("пять")` — в строке не число |
| `IndexError` | Нет элемента с таким номером | Список короче, чем ты думаешь; счёт с нуля |
| `KeyError` | Нет такого ключа в словаре | Опечатка в ключе, проверь через `in` |

Python 3.13 часто подсказывает сам: `Did you mean: 'score'?` — это значит «может, ты имел в виду…».
