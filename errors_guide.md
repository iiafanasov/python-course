# Что делать, если программа выдала ошибку

Ошибки бывают у всех программистов. Сообщение об ошибке — это подсказка, где искать.

## Алгоритм

1. Прочитай **последнюю строку** сообщения: там тип ошибки и подсказка.
2. Найди **номер строки** (`line 2`) и посмотри на неё и на строку выше.
3. Сравни с таблицей ниже.
4. Выведи значения переменных через `print(...)` перед строкой с ошибкой.
5. Только после этого зови учителя.

## Как читать сообщение об ошибке

Сообщение об ошибке называется **traceback**. Читай его **снизу вверх**:

```
Traceback (most recent call last):
  File "shop.py", line 2, in <module>
    print("Цена: " + price)
          ~~~~~~~~~^~~~~~~
TypeError: can only concatenate str (not "int") to str
```

- Последняя строка — **что случилось**: `TypeError`, нельзя склеить строку и число.
- Выше — **где**: файл `shop.py`, строка 2, и сама строка кода.
- Значки `~~~^~~~` показывают, какое именно место не понравилось Python.

## «Did you mean…?»

```
NameError: name 'scor' is not defined. Did you mean: 'score'?
```

`Did you mean: 'score'?` значит «может, ты имел в виду `score`?». Чаще всего это опечатка в имени.

## Частые ошибки

| Ошибка | Что значит | Где искать |
| --- | --- | --- |
| `SyntaxError` | Python не понял запись | Двоеточие после `if`/`for`/`while`, закрытые кавычки и скобки |
| `IndentationError` | Отступ не на своём месте | Тело `if`/`for`/`while` сдвинуто на 4 пробела |
| `NameError` | Такого имени нет | Опечатка в имени переменной, переменная ещё не создана |
| `TypeError` | Действие не подходит для такого типа | Строка + число: `"Очки: " + 5` → используй f-строку |
| `ValueError` | Значение не подходит | `int("пять")` — в строке не число |
| `IndexError` | Нет элемента с таким номером | Список короче, чем ты думаешь; счёт с нуля |
| `KeyError` | Нет такого ключа в словаре | Опечатка в ключе, проверь через `in` |

Новые ошибки добавятся в таблицу, когда мы до них дойдём.
