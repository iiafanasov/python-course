# Шпаргалка по Python

## Переменные и имена

```python
player_name = "Рекс"     # строка
lives_left = 3           # целое число
speed = 2.5              # дробное число
```

Правила имён:
- английские слова маленькими буквами через `_`: `max_score`, `lives_left`;
- имя объясняет, что лежит внутри: `score`, а не `a` или `x1`;
- нельзя начинать с цифры: `2lives` — ошибка;
- нельзя называть переменные как встроенные команды: `print`, `input`, `list`, `str`;
- однобуквенные имена можно только для счётчика цикла: `i`.

## Ввод и вывод

```python
name = input("Как тебя зовут? ")      # input всегда возвращает строку
age = int(input("Сколько тебе лет? ")) # int() превращает строку в число
print(f"Привет, {name}! Тебе {age}")   # f-строка подставляет значения
```

Частая ошибка: `input()` возвращает строку, поэтому `"2" * 3` даст `"222"`, а не `6`.

## Числа

```python
total = 7 + 3 * 2    # 13
half = 7 / 2         # 3.5 — обычное деление
whole = 7 // 2       # 3 — деление без остатка
rest = 7 % 2         # 1 — остаток (чётное число: n % 2 == 0)
```

## Строки

```python
word = "Python"
word[0]        # "P" — первая буква (счёт с нуля)
word[-1]       # "n" — последняя
len(word)      # 6 — длина
word.upper()   # "PYTHON"
```

## Условия

```python
if score >= 100:
    print("Победа!")
elif score >= 50:
    print("Почти!")
else:
    print("Ещё попытка")
```

Частая ошибка: забыть двоеточие `:` или отступ (4 пробела).

## Цикл for

```python
for i in range(3):        # i = 0, 1, 2 (до 3, не включая)
    print(i)

for item in ["меч", "щит"]:
    print(item)
```

## Цикл while

```python
lives = 3
while lives > 0:
    print(f"Жизней: {lives}")
    lives -= 1
```

Частая ошибка: забыть изменить переменную внутри цикла, и он станет бесконечным. Остановить программу — красный квадрат в PyCharm.

## Списки

```python
items = ["меч", "щит"]
items.append("лук")    # добавить в конец
items[0]               # "меч"
len(items)             # 3
"щит" in items         # True
```

## Словари

```python
hero = {"name": "Рекс", "hp": 30}
hero["hp"] -= 5                  # изменить значение
hero["level"] = 2                # добавить ключ
for key, value in hero.items():  # перебрать пары
    print(key, value)
```

Частая ошибка: `KeyError` — такого ключа нет в словаре.
