# Словарик программиста

Английские слова пригодятся: их пишет Python в сообщениях об ошибках. Новые слова добавляем на занятиях.

| Слово | По-английски | Что значит | Пример |
| --- | --- | --- | --- |
| Программа | program | Список команд, которые компьютер выполняет по порядку, сверху вниз | файл `shop.py` |
| Запуск | run | Компьютер начинает выполнять программу | зелёный треугольник ▶ в PyCharm |
| Переменная | variable | Коробка с наклейкой: у неё есть имя и значение внутри | `score = 0` |
| Значение | value | То, что лежит в переменной | `0` в `score = 0` |
| Строка | string, `str` | Текст в кавычках | `"Привет"` |
| Целое число | integer, `int` | Число без запятой | `42` |
| Дробное число | float | Число с точкой | `2.5` |
| Ввод | input | Программа спрашивает, ты отвечаешь с клавиатуры | `name = input("Имя? ")` |
| Вывод | output, `print` | Программа пишет на экран | `print("Привет")` |
| f-строка | f-string | Строка, в которую вставляются значения переменных | `f"Очки: {score}"` |
| Условие | condition, `if` | Проверка «да или нет»: от неё зависит, что сделает программа | `if lives > 0:` |
| Отступ | indent | 4 пробела в начале строки: показывают, что строка внутри `if`, `for` или `while` | тело цикла |
| Цикл | loop | Повтор одних и тех же команд | `for i in range(5):` |
| Список | list | Ряд пронумерованных ячеек | `["меч", "щит"]` |
| Индекс | index | Номер ячейки в списке или буквы в строке, счёт с нуля | `items[0]` |
| Словарь | dictionary, `dict` | Карточка персонажа: у каждого поля есть название (ключ) и значение | `{"hp": 30}` |
| Ключ | key | Название поля в словаре | `"hp"` |
| Ошибка | error | Python не смог выполнить строку и остановил программу | `NameError` |
| Traceback | traceback | Сообщение об ошибке; читаем снизу вверх | см. `errors_guide.md` |
