# Модуль 4. Игры на Pygame Zero

Что научусь делать:
- строить игровой цикл, управлять героем;
- проверять столкновения;
- делать уровни и рекорды.

Проекты в конце модуля: **Аркада** (папка `project/`) и **игра по своей идее** (папка `project2/`).

PyCharm подчёркивает в играх слова `Actor`, `screen`, `keyboard`. Это нормально: Pygame Zero сам подставляет их при запуске. Ничего чинить не нужно.
