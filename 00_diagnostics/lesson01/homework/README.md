# ДЗ к занятию 2 (25–30 мин)

1. Выбери 4 свои старые программы.
2. Положи их копии в папку `old_programs/`.
3. Переименуй переменные по правилам:
   - английские слова маленькими буквами через `_`;
   - имя объясняет, что внутри (`score`, а не `a`);
   - однобуквенные имена — только счётчик цикла `i`;
   - не называй переменные `list`, `str`, `input`, `print`.
4. Запусти каждую программу и проверь, что она работает как раньше.
5. Выбери одно переименование, которым гордишься, — расскажешь на занятии.

Совет: в PyCharm переименовать переменную сразу везде можно так: поставь курсор на имя и нажми **Shift+F6**.
