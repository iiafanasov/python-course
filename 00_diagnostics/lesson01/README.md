## 1. Переменная (variable) — коробка с наклейкой

Наклейка — это имя, а внутри лежит значение. Значение можно поменять.

```python
player_name = "Рекс"
lives_left = 3
lives_left = lives_left - 1   # теперь в коробке 2
```

## 2. Правила имён

- Английские слова маленькими буквами через `_`.
- Имя говорит, что лежит внутри.
- Нельзя начинать с цифры.
- Нельзя называть как встроенные команды Python.

| Так понятно | Так не стоит | Почему |
| --- | --- | --- |
| `player_name` | `a` | Непонятно, что внутри |
| `lives_left` | `2lives` | Начинается с цифры — Python выдаст ошибку |
| `max_score` | `MaxScore` | Так пишут другие вещи, не переменные |
| `score` | `ochki` | Транслит, лучше английское слово |
| `items` | `list` | `list` — встроенная команда Python |

## 3. Ввод (input) и вывод (print)

```python
name = input("Как тебя зовут? ")
print(f"Привет, {name}!")
```

`input` задаёт вопрос и ждёт, что ты напечатаешь. `print` выводит на экран. Буква `f` перед кавычками позволяет вставлять переменные в фигурных скобках.
