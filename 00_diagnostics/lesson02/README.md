# Занятие 2. Разведка перед сезоном

Сегодня мы узнаем, что ты помнишь после перерыва. Это не контрольная и не оценка — просто разведка, чтобы понять, с чего начинать сезон.

## Что делаем

1. **Предсказываем.** Файлы `predict_01.py` … `predict_08.py`. Сначала запиши на бумаге, что выведет программа. Только потом запускай и сравнивай.
2. **Решаем задачи.** `task_a_even.py` → `task_b_grades.py` → `task_c_inventory.py`. Задача `task_d_star_rounds.py` — «звёздочка», если останется время.
3. **Отмечаем, что помним.** Заполни таблицу в `self_assessment.md`.

## Помни

- Сначала ответ на бумаге — потом запуск. Если не совпало, это не ошибка, а находка: разберёмся, почему.
- Запускай программу после каждых 2–3 новых строк.
- Ошибка — это подсказка. Читай последнюю строку сообщения (см. `errors_guide.md`).
