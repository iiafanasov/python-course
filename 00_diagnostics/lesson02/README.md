# Занятие 2. Разведка перед сезоном

**Что ты узнаешь:** что ты помнишь после перерыва и с чего начнём новый сезон.

Это не контрольная и не оценка. Просто разведка.

## Порядок работы

1. **Предсказываем.** Файлы `predict_01.py` … `predict_08.py`. Сначала запиши на бумаге, что выведет программа. Потом запусти и сравни.
2. **Решаем задачи.** `task_a_even.py` → `task_b_grades.py` → `task_c_inventory.py`.
3. **«Звёздочка» (по желанию).** `task_star_rounds.py` — если останется время.
4. **Отмечаем, что помним.** Заполни таблицу в `self_assessment.md`.

ДЗ — в папке `homework/`, начни с `homework/README.md`.

## Помни

- Если ответ не совпал — это не провал, а находка. Разберёмся, почему так.
- Запускай программу после каждых 2–3 новых строк.
- Ошибка — это подсказка. Читай последнюю строку сообщения (см. `errors_guide.md`).
