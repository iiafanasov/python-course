# Задача Парсонса

Программа должна посчитать, сколько чисел в списке больше 10, и вывести ответ.

Строки программы перепутаны. Каждая строка подписана буквой. Одна строка лишняя: в ней ошибка.

| Буква | Строка |
| --- | --- |
| А | `print(f"Больше 10: {count}")` |
| Б | `if number > 10:` |
| В | `numbers = [4, 15, 8, 23, 11, 2]` |
| Г | `count = count + 1` |
| Д | `for number in numbers:` |
| Е | `count = 0` |
| Ж | `if number > 10` |

## Что сделать

1. Найди лишнюю строку. Запиши её букву и что в ней не так.
2. Выпиши остальные буквы в правильном порядке, по одной на строке. Если строке в программе нужен отступ, поставь перед буквой 4 пробела. Если двойной отступ — 8 пробелов.
3. Создай рядом файл `parsons_solution.py`, набери программу в своём порядке и запусти. Сработало?

## Пример (разбирали на занятии)

| Буква | Строка |
| --- | --- |
| А | `print("Готово")` |
| Б | `for i in range(1, 4):` |
| В | `print(i)` |

Ответ:

```

```

`В` с отступом — это тело цикла. `А` без отступа — выполнится один раз, после цикла.
