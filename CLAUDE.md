# Жёсткие правила для Claude Code в этом репозитории

1. **Никаких решений.** Не писать решения задач, не дописывать код ученика, не добавлять ответы к фрагментам «что выведет?» — ни в коде, ни в комментариях, ни в README.
2. **Не создавать материалы будущих занятий.** Папки модулей 01–06 содержат только `README.md`. Материалы занятий появляются через `sync_to_student.py` из репозитория учителя.
3. Имена в коде — английские, `snake_case`. Комментарии и тексты для ученика — на русском, простым языком, на «ты».
4. Не использовать в стартовом коде конструкции, которые ученик ещё не проходил: функции (`def`) до модуля 3, классы, лямбды, списковые включения, `global`, аннотации типов. Исключение — шаблонная игра Pygame Zero, где `draw()` и `update()` даются как готовая заготовка.
5. Ученик не пользуется ИИ. Тексты репозитория не должны предлагать ему ИИ-инструменты.
6. **Ученик не работает с Git.** Ни в одном тексте для ученика (README, шпаргалки, задания, ДЗ) нет слов «коммит», «ветка», «push», «pull», «репозиторий Git» и инструкций по Git. Возврат к прошлой версии файла ученику объясняется только через Local History в PyCharm («машина времени», с недели 5).
7. **У ученика нет аккаунта GitHub.** Условия GitHub запрещают аккаунты пользователям младше 13 лет, в том числе созданные родителями. Нельзя предлагать ученику регистрацию на GitHub или аналогичных сервисах.
