# Мой курс Python 🐍

Здесь живёт весь мой код: задачи с занятий, домашние задания и проекты.
К концу года тут будет 7 проектов, включая две собственные игры.

## Как всё устроено

| Папка | Что внутри |
| --- | --- |
| `00_diagnostics` | Вспоминаем, что уже умеем |
| `01_logic` | Условия, случайные числа, поиск ошибок. Игра «Угадай число» |
| `02_data` | Списки, словари, строки. Текстовая RPG |
| `03_functions` | Функции, тесты, сохранение в файл |
| `04_games` | Игры на Pygame Zero: аркада и своя игра |
| `05_practice` | Программы для реальной жизни или микроконтроллер |
| `06_final` | Мой итоговый проект |

В каждом занятии есть папка `lessonNN` (NN — номер занятия), а в ней папка `homework` с домашним заданием.

## Полезное

- `cheatsheet.md` — шпаргалка по Python.
- `errors_guide.md` — что делать, если программа выдала ошибку.
- `skills_map.md` — моя карта навыков.
- `portfolio.md` — мои проекты.
- `dream_project.md` — что я хочу сделать.

## Правила

1. Код набираю сам, а не копирую.
2. Запускаю программу после каждых 2–3 новых строк.
3. Ошибка — это подсказка, а не провал. Сначала читаю последнюю строку ошибки.
4. Прежде чем звать на помощь, делаю три попытки: перечитываю ошибку, вывожу переменные через `print`, пробую что-то изменить.

## Для учителя

### Установка

```bash
python3.13 -m venv .venv
# Windows: .venv\Scripts\activate    macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python tools/check_setup.py
python tools/check_pgzero.py   # должно открыться окно, закрыть его
```

`python -m pytest` пока завершается с кодом 5 («no tests collected») — тестов в репозитории ещё нет, это нормально. Тесты появятся с модуля 3.

### Настройки PyCharm

- Интерпретатор: `.venv` (Python 3.13).
- Отключить AI Assistant и Full Line Code Completion: Settings → Plugins (AI Assistant — Disable), Settings → Editor → General → Inline Completion — выключить.
- Шрифт редактора — 16–18 pt, номера строк включены.
- PyCharm подчёркивает `Actor`, `screen`, `keyboard` в играх Pygame Zero как неизвестные имена. Это нормально: Pygame Zero подставляет их при запуске.

### Pygame Zero и кириллица

Встроенный шрифт Pygame Zero поддерживает кириллицу (проверено: Python 3.13, pgzero 1.2.1, pygame 2.6.1), поэтому `tools/check_pgzero.py` и игры пишут текст по-русски.

### Как появляются материалы занятий

Материалы копируются из репозитория учителя `python-course-teacher` командой (запускать из него):

```bash
python tools/sync_to_student.py --week NN --student-repo <путь к python-course>
```

Решения и ответы никогда не попадают в этот репозиторий.
