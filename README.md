Здесь живёт весь мой код: задачи с занятий, домашние задания и проекты.
К концу года тут будет 8 проектов, и среди них две мои собственные игры.

| Папка | Что внутри |

**Главное правило: номер занятия = номер папки.** Занятие 2 — папка `lesson02`, занятие 17 — `lesson17`.

Внутри папки занятия:
- `README.md` — с него начинаю: тема и порядок работы;
- файлы `.py` — задачи с занятия;
- `homework/` — домашнее задание, туда же сдаю готовое.

Проект модуля лежит в папке `project/` этого модуля.

## Как запустить программу

Открой файл `.py` в PyCharm и нажми зелёный треугольник ▶ (Run) вверху справа.

## Правила

1. Код набираю сам, а не копирую.
2. Запускаю программу после каждых 2–3 новых строк.
3. Ошибка — это подсказка, а не провал. Сначала читаю последнюю строку ошибки.
4. Прежде чем звать на помощь, делаю три попытки: перечитываю ошибку, вывожу переменные через `print`, пробую что-то изменить.

## Для учителя

### Установка

```bash
python3.13 -m venv .venv
# Windows: .venv\Scripts\activate    macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python tools/check_setup.py
python tools/check_pgzero.py   # должно открыться окно, закрыть его
```

`check_setup.py` проверяет версию Python, `.venv`, `pgzero` и `pytest`, а ещё имена файлов: нет ли пробелов и кириллицы, не совпадает ли `.py` с модулем Python (`random.py`, `test.py` ломают импорт). Запускать после каждой синхронизации и перед проектными неделями.

`python -m pytest` пока завершается с кодом 5 («no tests collected») — тестов в репозитории ещё нет, это нормально. Тесты появятся с модуля 3. `pytest.ini` ищет только `test_*.py` в папках модулей, `sandbox/` и `tools/` не трогает.

### Настройки PyCharm

- Интерпретатор: `.venv` (Python 3.13).
- Отключить AI Assistant и Full Line Code Completion: Settings → Plugins (AI Assistant — Disable), Settings → Editor → General → Inline Completion — выключить. Обычное автодополнение оставить.
- Шрифт редактора — 16–18 pt, номера строк включены.
- EditorConfig (Settings → Editor → Code Style → Enable EditorConfig support) включён: `.editorconfig` задаёт UTF-8, LF и 4 пробела.
- PyCharm подчёркивает `Actor`, `screen`, `keyboard` в играх Pygame Zero как неизвестные имена. Это нормально: Pygame Zero подставляет их при запуске.

### Pygame Zero и кириллица

Встроенный шрифт Pygame Zero поддерживает кириллицу (проверено: Python 3.13, pgzero 1.2.1, pygame 2.6.1), поэтому папка `fonts/` не нужна, а `tools/check_pgzero.py` и игры пишут текст по-русски.

### Как появляются материалы занятий

Материалы копируются из репозитория учителя `python-course-teacher` командой (запускать из него) не раньше чем за день до занятия:

```bash
python tools/sync_to_student.py --week NN --student-repo <путь к python-course>
```

Решения и ответы никогда не попадают в этот репозиторий.

### Git

- Одна ветка `main`.
- До недели 14 коммитит учитель: `chore: add lesson NN materials` после синхронизации, `lesson NN: classwork` после занятия.
- С недели 14 ученик коммитит сам через PyCharm (Commit, History, Rollback), сообщения на русском, например `сделал магазин в RPG`. Git-автор ученика — имя без фамилии, email — `noreply`.
- Удалённый репозиторий — только приватный.
- Сохранения и рекорды игр (`save*.json`, `*_save.json`, `records*.json`) в git не попадают.
